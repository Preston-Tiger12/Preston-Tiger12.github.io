# Ntwali Preston (Tiger) · Portfolio

Live site: https://preston-tiger12.github.io

Interactive engineering portfolio for a Mechanical Engineering student (Robotics, Mechatronics, Avionics and Space) at the University of Hull.

- **3D scenes in three.js:** a code-modelled F1 car with an exploded-view inspector, a private jet flying in formation with two fighters, and a rocket.
- **Project pages:** a self-powered satellite using a solar-thermal TEG system (SolidWorks), and a piezoelectric vibration harvester (MATLAB and Simulink).
- **Built with:** vanilla JavaScript, three.js, GSAP and Lenis. No build step; it's served as static files.
